# kite_ui example

A one-screen dashboard showing the widgets in context: `KiteStatGrid`,
`KiteCard`, `KiteSparkline`, `KiteDonut` and `KiteButton`.

This directory ships only `lib/main.dart` — package examples leave out the
platform folders so the published archive stays small. Generate them first:

```bash
flutter create . --platforms web
flutter run -d chrome
```
